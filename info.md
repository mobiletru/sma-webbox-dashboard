# SMA Webbox Dashboard

Live monitoring and parameter controls for **SMA Sunny Island SI6048UM** inverters via Home Assistant WebBox MQTT.

## Quick open

After install, open the dashboard at:

`/local/community/sma-webbox-dashboard/index.html`

Authenticate once with a [long-lived access token](https://www.home-assistant.io/docs/authentication/#your-account-profile).

## Requires

- Home Assistant 2023.0+
- Sunny Island WebBox MQTT sensors (or compatible entity IDs in `js/config.js`)
- WebBox integration for writable parameter controls (optional)
